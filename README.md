# 居家安全 · 防拐骗语音演练

一个给小学生用的交互式防拐骗演练网页。孩子独自在家时，会模拟三种上门场景（邻居王奶奶、快递员、修水管工人），孩子用打字或语音回答，角色会根据回答推进剧情，最后给出防范评价。

## 在线访问

打开本仓库启用 GitHub Pages 后的网址即可，无需安装任何软件。

> 推荐使用 **Microsoft Edge** 浏览器打开。
> Chrome 在国内无法完成语音识别（麦克风说话），但打字回答完全正常。

## 纯本地判断，无需任何 API

- 本页面**不接大模型、不需要 API Key**，完全离线可跑。
- 语音回答 → 浏览器语音识别转文本 → 页面内置的**本地判断逻辑**（字段提取 + 加权匹配）从音频库里挑出对应回复 → 播放预录音频。
- 三个角色的预录音频（音色各不相同：王奶奶=苍老女声、快递员=年轻男声、修水管工人=沉稳男声）都打包在 `audio/` 里。

## 使用说明

1. 打开网页后，点一下屏幕任意位置开始播放声音（浏览器要求先有一次点击）。
2. 选择一个场景（王奶奶 / 快递员 / 维修工）。
3. 听完敲门声和角色开场白后，用打字或麦克风回答对方。
4. 说出"报警 / 叫家长 / 看证件 / 视频通话"等警惕词，会立刻触发"成功防范"结算。

## 本地运行

本目录是纯静态文件，无需服务器。双击 `index.html` 即可在浏览器中体验；
此时麦克风在 Chrome 中通常可用（与语音识别服务一致），若浏览器拦截则在地址栏允许麦克风即可。

## 目录结构

```
├── index.html      网页本体（图片、样式、脚本全部内嵌）
├── audio/          18 个 MP3：1 个敲门声 + 17 段角色预录台词
└── .nojekyll      （GitHub Pages 用，请勿删除）
```

## 关于语音

- 三个角色的**固定台词**（开场白、标准应答、兜底、撤退）由 `audio/` 下的 MP3 播放，音质稳定。
- 学生回答后角色的动态回复同样来自音频库；找不到匹配时用浏览器内置语音兜底（音质一般）。
